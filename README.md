# 🎬 Movie Explorer Application

A responsive React application where users can browse, search for movies/shows, and view detailed information in an interactive modal overlay. Built using TVMaze API.

## 🚀 Features
- **Responsive Home Page**: Beautiful hero section with navigation.
- **Movie Listing**: Grid layout displaying movies/shows with cards.
- **Dynamic Search**: Live search functionality fetching data from TVMaze API.
- **Interactive Modal**: Detailed view of the selected movie/show with image, rating, release date, and summary.
- **Fully Responsive**: Mobile, tablet, and desktop optimized UI using Tailwind CSS.

## 🛠️ Tech Stack
- **Frontend**: React.js, React Router
- **Styling**: Tailwind CSS
- **API**: [TVMaze API](https://www.tvmaze.com/api)
